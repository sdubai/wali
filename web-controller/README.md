# 局域网遥控页面

页面通过 EMQX WebSocket 监听器连接 MQTT。默认地址是 `ws://192.168.31.248:8083/mqtt`。

在本目录启动静态服务器：

```bash
python3 -m http.server 8080
```

手机访问 `http://运行网页机器的IP:8080/`。必须按住方向键才会持续刷新行走指令，松手立即发送停止；运动板还有独立超时停车保护。

页面还会显示语音板的局域网摄像头画面。语音板通过保留主题
`walle/camera/url` 发布当前流地址，页面订阅后自动更新；连接设置区域上方也可手工
填写 `http://设备IP:81/stream`。摄像头目前只支持一个同时观看的页面。
